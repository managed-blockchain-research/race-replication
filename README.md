# RACE harness (caliper-stress-test)

Caliper benchmark harness for the RACE evaluation. Companion to the
paper source (`banning` repo, `race` branch / `papers/race/`) and the
published replication package: https://github.com/managed-blockchain-research/race-replication

See that replication package's README for the required Caliper
ethereum-connector patch (nonce-reset trigger strings), dataset
descriptions, and result data.
